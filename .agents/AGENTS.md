# Regras do Projeto - TaskFlow

Consulte [GEMINI.md](file:///c:/Users/larip/.gemini/antigravity/scratch/sistema_demo/.agents/GEMINI.md) para as regras completas do projeto.

## 1. Stack Tecnológica
- **Front-end**: HTML5 semântico, CSS Vanilla (variáveis HSL, tema escuro moderno, glassmorphism, animações sutis), JavaScript (ES6+ modular).
- **Persistência**: LocalStorage com dados mockados iniciais.
- **Fontes & Ícones**: Google Fonts (Outfit / Inter) e Lucide Icons (via CDN).

## 2. Estrutura de Pastas
- `css/styles.css`: Sistema de design e estilos.
- `js/app.js`: Lógica principal da aplicação.
- `js/store.js`: Gerenciador de estado e persistência.
- `js/ui.js`: Renderização de componentes e manipulação do DOM.
- `index.html`: Estrutura HTML semântica.
